1. What Is Malware?

Definition

Malware (malicious software) is any program intentionally designed to damage systems, steal data, or gain unauthorized access to computing resources. The key word is intentional — bugs or errors in software are not malware.

Think of malware like a burglar who can wear many disguises: sometimes it's a thief stealing your passwords, sometimes it's a vandal destroying your files, sometimes it's a spy silently watching, and sometimes it's a kidnapper locking your files until you pay a ransom.

⚡ Key Insight — Always Exam-Tested

Most malware relies on human interaction at some point — making user awareness the first line of defense. Technology alone cannot stop malware if humans are tricked.

2. The 4 Objectives of Malware (CIA + Control)

Malware attacks the three classic pillars of information security — and adds a dangerous fourth dimension:

ConfidentialityYour secretsSteal credentials, PII, financial records, IPKeyloggers, spyware

Malware must reach its victim before it can do anything. The five main spread channels are:

  • Email — Malicious attachments, embedded links, macro-enabled documents. Remains the #1 initial access vector.
  • Web — Drive-by downloads (visiting a compromised site silently downloads malware), malvertising (malicious ads), watering-hole attacks (compromise sites the target visits).
  • Downloads — Fake installers, trojanized software, cracked applications ("free" software that hides malware).
  • Network — Worms that scan for exposed services and exploit unpatched vulnerabilities to spread automatically.
  • Removable Media — USB drives with autorun payloads. Especially dangerous in air-gapped environments (systems isolated from the internet).
Common Infection Vectors
  • Macro-Enabled Documents — Office files; user clicks "Enable Content" → VBA macro executes
  • Browser/Plugin Exploits — Vulnerabilities in browsers, Java, Flash, PDF readers
  • Stolen Credentials — Attacker logs in manually using harvested passwords
  • Compressed Archives — ZIP/RAR hiding executables (e.g., invoice.pdf.exe)
  • Supply-Chain Attacks — Compromised software updates through trusted vendors

Once on the system, malware needs to execute and persist (survive reboots).

Execution TypeHow
User-TriggeredVictim opens a file, runs installer, enables macros
AutomaticExploit chains or worm behavior — no user action needed

Persistence mechanisms ensure malware survives a reboot:

  • Registry keys (Windows auto-runs)
  • Startup folders
  • Scheduled tasks
  • System services

The payload is the final malicious action: steal data, encrypt files, spy on users, control the system, or move laterally.

The longer malware hides, the more damage it inflicts. Modern malware invests heavily in evasion:

  • Obfuscation & Packing — Code is scrambled or compressed so signature-based tools can't match known patterns
  • Anti-VM / Anti-Sandbox — Detects analysis environments and refuses to run, frustrating reverse engineers
  • Delays & Staged Downloads — Sleeps before executing, or downloads payload in stages to bypass initial scans
  • Rootkits — Kernel-level tools that hide processes, files, and network connections from the OS itself
  • Encrypted C2 Traffic — Command-and-control communications disguised as normal HTTPS traffic

How defenders prevent, detect, respond to, and recover from compromise. This covers: layered controls, patching, backups, incident response — detailed in the Defense Playbook.

4. Malware Families — Detailed Breakdown

Definition: A virus attaches to a legitimate host file (document, script, executable) and spreads when that file is opened or executed. Unlike worms, viruses require user action to propagate.

Program Viruses specifically target executables (.exe, .dll, .com), injecting code into the binary. Every run → virus activates → seeks more executables.

VirusYearMethodImpact

ILOVEYOU2000VBScript worm/virus hybridSpread via email, ~$10 billion in damages
CIH (Chernobyl)1998Program virusOverwrote flash BIOS — physically bricked machines

Definition: Self-replicating malware that spreads across networks without needing a host file and without user action. Exploits network protocols and vulnerabilities.

Key Difference from Virus: No host file needed, no user action required.

  • Consume massive bandwidth → network outages
  • Often drop additional malware (ransomware, backdoors, cryptominers)
Historical Examples
  • Morris Worm (1988) — First major Internet worm; infected ~6,000 machines (≈10% of the Internet)
  • NotPetya — Used worm-like spread to cripple global enterprises in hours

Definition: Disguises itself as legitimate software but carries hidden malicious functionality. Does NOT self-replicate — relies entirely on social engineering.

⚠️ Double Extortion

Modern ransomware gangs exfiltrate data before encrypting it, threatening public release to increase payment pressure. This means even restoring from backup doesn't eliminate the threat.

Notable examples: CryptoLocker (2013), WannaCry (2017)

TypeWhat It DoesExamples
SpywareSilently monitors user activity; exfiltrates to attackerScreen capture, clipboard monitoring, mic/camera activation
KeyloggersRecords every keystrokeCredential harvesting, session token capture, form-field interception

Defense: MFA (stolen passwords alone aren't enough), least-privilege, EDR, behavioral monitoring

Adware: Injects unwanted ads, tracks browsing behavior for profit.

Browser Hijackers: Change homepage, search engine, and security settings without consent.

While dismissed as nuisances, real risks include:

  • Privacy loss through behavioral tracking
  • Exposure to additional malware through malicious ad networks
  • Weakened browser security settings
  • Degraded system performance

Most bundled with "free" software installers — always use custom installation and review what's included.

Definition: A network of compromised devices (computers, servers, IoT) silently controlled by an attacker through a C2 (Command-and-Control) infrastructure. Individual infected devices = "bots" or "zombies."

Use CaseDescription
DDoS AttacksOverwhelm targets with traffic, disrupting services
CryptominingSteal compute resources to mine cryptocurrency silently
Spam & PhishingDistribute millions of emails from hard-to-block IPs
FraudCredential stuffing, click fraud, financial theft at scale
Case Study: Mirai Botnet (2016)

Exploited default passwords on IoT devices to build a massive army that launched record DDoS attacks, taking down DNS provider Dyn and disrupting Twitter, Netflix, Reddit.

Social engineering manipulates human psychology to bypass technical controls.

TypeChannelDescription
PhishingEmailMass emails impersonating trusted brands with generic lures
Spear PhishingEmailHighly targeted messages crafted with personal details
SmishingSMSSMS-based phishing exploiting mobile trust
VishingVoiceCalls impersonating IT support, banks, or government

Red flags: Urgency language, unusual sender addresses, spoofed domains, unexpected attachments, requests that bypass normal approval.

Defense: Training + simulations, out-of-band verification, MFA, email gateways, DMARC/DKIM/SPF enforcement.

5. WannaCry — The Key Case Study

WannaCry (2017) is the most important ransomware case study. It combined ransomware with a worm-like propagation mechanism.

  • Exploited the EternalBlue vulnerability in Windows SMB protocol
  • Spread automatically across networks without user interaction (worm behavior)
  • Encrypted files and demanded Bitcoin ransom
  • Affected 200,000+ systems in 150 countries
  • Hit hospitals (NHS in UK), telecoms (Spain), banks — causing ~$4–8 billion in damages
  • Lesson: Patch management is critical — a patch for EternalBlue had existed for weeks

Common Exam Traps ⚠️

Trap #1 — "Worms need a host file"

❌ WRONG. Worms do not need a host file. They are standalone self-replicating programs. Viruses need host files.

Trap #2 — "Trojans self-replicate"

❌ WRONG. Trojans do NOT self-replicate. That's their key distinguishing feature. They rely entirely on social engineering.

Trap #3 — "Backups fully solve ransomware"

❌ WRONG with modern ransomware. Double extortion means attackers exfiltrate data first. Even with backups, they can still leak your data publicly.

Trap #4 — "Adware is harmless"

❌ WRONG. Adware exposes you to malicious ad networks, weakens browser security, and tracks your behavior extensively. Real security risk.

Trap #5 — "Email is just one of many equal vectors"

❌ Incomplete. Email is specifically the #1 initial access vector for most campaigns. Know this distinction.
